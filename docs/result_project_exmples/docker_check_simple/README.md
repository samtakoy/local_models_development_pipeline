# Temperature Converter

Локальное веб-приложение для конвертации температур между °C и °F.

## Установка

```bash
uv sync
```

## Запуск

```bash
uv run python src/app.py
```

Приложение стартует на `http://127.0.0.1:8050`.

## Проверка

Открыть браузер на `http://127.0.0.1:8050` — увидеть форму ввода температуры.

- Введите значение температуры в поле ввода.
- Выберите направление конвертации из выпадающего списка: °C → °F или °F → °C.
- Нажмите кнопку «Перевести».
- Результат отображается ниже с точностью до одного знака после запятой.

Ожидаемые результаты для распространённых значений:
- 25 °C → 77.0 °F
- 32 °F → 0.0 °C
- 100 °C → 212.0 °F
- -40 °C = -40.0 °F

## Обработка ошибок

Если ввести нечисловое значение (например, "abc", "$#", пустую строку),
приложение отображает сообщение об ошибке
«Please enter a valid number» вместо краха. Форма остаётся доступной
для повторного ввода.

- Не число → ошибка, HTTP 200
- Пустая строка → ошибка
- Валидное число → результат с точностью до одного знака

## Тесты

```bash
uv run pytest
```

Тесты ошибок: `tests/test_app_errors.py`.

## Архитектура (кратко)

- `src/app.py` — Flask приложение, роуты, обработка ошибок и логирование.
- `src/core/converter.py` — функции конвертации температур (celsius_to_fahrenheit, fahrenheit_to_celsius).
- `src/templates/` — HTML-шаблоны: `base.html` (общий макет), `index.html` (главная страница с формой).
