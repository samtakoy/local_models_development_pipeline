# Общее описание

Текстовый файл с набором карточек содержит:
- дату создания набора (опционально),
- название набора (опционально),
- подробное описание (оционально)
- сами карточки 

Например:
```
date:06-06-2026 00:00:01

title:заголовок
и даже на несколько строк
desc: описание

тоже на несколько строк можно

q: первая карточка - вопрос
(да и тут можно)
a: ответ многострочный тоже
...

#какой-то тег# еще тег можно с пробелом#еще

q: 
вторая карточка - вопрос (пользователь набил так)
(да и тут можно)

(сколько угодно строк - как захотелось пользователю)
a: 

ответ на второй вопрос польщователь решил записать после нескольких холостых пробелов и переносов строк
многострочный тоже
...
(теги могут быть, а могут не быть)

и т.д.

```

# Файл

Кодировка файла - UTF-8.
Допустимые концы строк - LF и CRLF.


## Ключевые слова которые делят файл на разделы

Всего 5:
```
date:
title:
desc:
q:
a:
```
Каждое ключевое слово обязательно строчное и всегда идет с начала строки.

При нарушении: заглавные буквы или любые символы или пробелы перед ключевым словом - считается что такая строка содержит обычный текст.

Правило детекции ключевого слова: 
- одно из списка (из 5 шт перечисленных выше)
- с начала строки
- точное совпадение вплоть до символа `:`

Любой текст после символа `:`  ключевого слова считается обычным текстом.

## Разделы
Ключевые слова бьют файл на разделы. Все символы в файле за исключением текста ключевых слов
- это полезный текст который надо извлечь.

# Парсинг

## Порядок разбора

1) разбить весь текст файла карточек по разделителю: <начало строки>`q:`

- все что попало в первый блок (до первого `q:`) - может содержать только блоки с ключевыми словами `date:`, `title:`, `desc:`
  кусок текста из этого блока будем ниже называть напкой
- все остальные блоки из разбиения - содержать карточки

3) Из шапки извлечь текст который содержался в разделах `date:`, `title:`, `desc:`
После извлечения сделать trim() - обрезать крайние побелы и крайние переносы строк


4) Распарсить блок каждой карточки
Весть текст до `a:` это текст вопроса
Весь текст после `a:` это текст ответа

`q:` и `a:` не должны остаться в итоговом тексте

если в карточке нет ключевого слова `a:` - значит карточка не содержит ответа - это нормально

5) текст вопроса и ответа после извлечения - также обработать с помощью стандартного trim():
 образать в начала и в конце пробельные символы и переносы строк (только с краев)

6) после извлечения и обработки текста ответа - проверить его последнюю строку:
  если она начинается с первого символа решетки `#` - значит это строка с тегами карточки,
  ее надо вырезать из текста ответа

7) если у карточки была найдена строка тегов то обработать ее - извлечь теги:
 - разбить на части по символу #
 - к каждой части применить trim()
 - все получившиеся непустые части считать тегами карточки



## trim()
упоминаемая функция trim() выше обозначает метод который у любой строки отбрасывает все ведущие и концевые пробельные символы и символы переноса строк (только в начале и конце текста)



## Шапка (первая часть файла до первого `q:`)

В шапке действуют только ключевые слова `date:`, `title:`, `desc:`.

- Они могут идти в любом порядке.
- Все три необязательные: если поля нет в наборе, его значение - пустая строка.
- Если поле встречается в шапке несколько раз - берется первое значение, повторы игнорируются.


## Описание разделов

### date:
Время создания набора карточек. Формат:
ДД-ММ-ГГГГ ЧЧ:ММ:СС

Пример:
```
date:06-06-2026 00:00:01
```
или так

```
date:  06-06-2026 00:00:01
```
так тоже можно
```
date:

06-06-2026 00:00:01

   
```

Для простоты храним строку даты как текстовую строку (не парсим в другие типы)

### `title:`
Название набора карточек - текст, в котором допустимы переносы строк.

### `desc:`
Описание набора карточек - текст, в котором допустимы переносы строк.

### `q:`
Раздел с многострочным текстом вопроса карточки.

### `a:`
Раздел с многострочным текстом ответа карточки.

### Теги
Строка тегов - строка, начинающаяся с символа `#` с самого первого символа строки.

- Строка тегов распознается только если это последняя непустая строка раздела `a:`.
- Если последняя непустая строка раздела `a:` не начинается с `#` - у карточки нет тегов.
- Строка с `#` в любом другом месте - обычный текст.
- Строка тегов удаляется из текста ответа

Пример
```
#тег1#тег2#тег3
```
Теги: `тег1`, `тег2`, `тег3`.

```
#latent optimization #x
```
Теги: `latent optimization`, `x`.
