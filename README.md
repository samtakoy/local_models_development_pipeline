## Финальная проверка в браузере (веб-тестировщик)

После последнего этапа веб-тестировщик запускает приложение и проходит требования заказчика в браузере
через Playwright MCP. Пишет отчёт и вердикт. Если приложение не принято, команда делает этап исправлений
по его отчёту, и проверка повторяется (один круг). Входит в список ролей по умолчанию.

Список ролей задаётся в файле состава проекта `set.toml`; без веб-тестировщика:

```toml
[pipeline]
roles = ["pm", "researcher", "architect", "architect_review", "senior", "developer", "developer_review"]
```

Что нужно на компьютере:
- Node.js с `npx`: Playwright MCP скачивается и запускается командой `npx @playwright/mcp@latest`;
- Google Chrome.

Окно браузера задаётся в `.env`: `BROWSER_HEADLESS=true` — без окна, `false` — с окном (удобно для отладки).
